# wechat-md

把公开的微信公众号文章保存为 Markdown，支持图片本地化、批量归档和正文引用链接发现。

**当前版本：1.1.0rc1，发布候选版。** Python 3.9+，运行时零第三方依赖。可以独立作为命令行工具使用，也可以作为 agent skill 安装。

## 快速开始

下载本仓库后，在包含 `wx2md.py` 的目录执行。将示例 URL 替换为实际文章链接。

```bash
python3 wx2md.py --help
python3 wx2md.py "https://mp.weixin.qq.com/s/ARTICLE_TOKEN" -o ./archive
python3 wx2md.py -f urls.txt -o ./archive --delay 3
python3 wx2md.py --discover "https://mp.weixin.qq.com/s/ARTICLE_TOKEN" > urls.txt
```

`urls.txt` 每行一个链接，支持 UTF-8 BOM、空行和以 `#` 开头的注释。发现模式只提取正文中的文章超链接，并按文章身份去重。

## 输出与状态

```text
archive/
  文章清单.csv
  <公众号>/articles/<日期>-<标题>-<文章ID>/
    <标题>.md
    images/
```

不同文章使用独立 ID，避免同日期、同标题或标题截断造成覆盖。长链接用 `__biz / mid / idx` 识别文章；短链接用路径标识。短长链接之间尚未自动关联，可能各保留一份。

Markdown 含标题、作者、发布日期、原始发布时间戳（若可提取）、来源 URL、抓取时间、文章 ID、状态及图片统计。日期按 UTC+8 计算。字数统计口径为正文中的汉字数加英文词数，不计图片 URL。

| 状态 | 含义 |
|---|---|
| `complete` | 正文和已识别的可下载图片已保存 |
| `remote` | 指定 `--no-images`，主动保留远程图片 |
| `partial` | 正文已保存，部分图片未本地化；默认输出失败原因 |

退出码：`0` 为按所选模式完成或已归档跳过，`1` 为失败、部分完成或访问受阻，`2` 为参数或输入错误。

`文章清单.csv` 使用 UTF-8 BOM，按文章 ID 更新，包含状态和 Markdown 内容哈希。再次运行会跳过完整文件，补抓部分完成、文件丢失或内容变化的条目。选择 `--no-images` 后，之后不带该参数运行仍会补抓图片。`--force` 更新同一篇文章并保持现有路径。

旧版清单仍可读取：下次抓取会补齐状态和哈希，来源匹配的旧文件原位更新。旧清单曾发生同名冲突时，不覆盖来源不匹配的旧文件，新文章写入带 ID 的目录。

## 常用参数

| 参数 | 说明 |
|---|---|
| `-o, --output DIR` | 输出目录，默认 `./wechat-md` |
| `-f, --file FILE` | 从文本文件读取链接 |
| `--no-images` | 主动保留远程图片 |
| `--image-workers N` | 图片并发 1–4，默认 2 |
| `--delay N` | 文章间隔，至少 2 秒，默认 2；也适用于发现模式 |
| `--timeout N` | 文章及图片单次请求超时，默认 30 秒 |
| `--retries N` | 暂时失败时最多尝试次数，包含首次；1–5，默认 3 |
| `--force` | 重新抓取并更新相同文章 |
| `--no-clean` | 保留普通文本节点中的 UI 噪音 |
| `--discover` | 只输出正文引用的文章链接 |
| `--insecure` | 关闭 TLS 证书验证，连接可能被冒充；默认关闭此选项 |
| `-v, --verbose` | 输出退避与下载诊断信息 |
| `--version` | 显示版本 |

## 支持范围

- 标题、段落、链接、加粗、引用、嵌套列表及有序列表编号。
- 代码块与行内代码独立处理，保留星号和中文空格，自动选择反引号围栏。
- 简单表格输出 Markdown；合并单元格表格标注后按行展开，不还原复杂布局。
- 图片优先读取 `data-src`，支持 PNG、JPEG、GIF、WebP 的基本文件特征检查。此检查不等于完整图片解码；SVG、AVIF 等其他格式保留远程引用并标记部分完成。
- 音视频输出能提取到的地址、标识或占位提示，不下载、不转写、不保证可播放。
- Markdown 特殊字符转义；发布日期不受运行机器时区影响；脚本、样式和明确隐藏的节点排除。

## 网络与恢复

仅请求 `mp.weixin.qq.com` 的文章，以及 `mmbiz.qpic.cn`、`mmbiz.qlogo.cn`、`wx.qlogo.cn` 的图片。输入、重定向和最终 URL 均检查主机与协议；不请求任意站点或 IP 地址。图片白名单外的引用不会下载，会在结果中说明。

默认验证 TLS，不使用 Cookie，不绕过验证码。HTML 上限 8 MiB，单张图片上限 20 MiB。超时与部分服务端暂时错误有限重试；404 等永久错误不重试。检测到验证页或 HTTP 401/403/429 后停止本批请求，图片并发中已经发出的请求可能仍会结束。归档模式写出 `待处理链接.txt`，发现模式将待处理链接输出到 stderr。具体受阻原因无法仅凭页面确定。

文件和清单分别用临时文件加原子替换写入；两者之间中断后可通过重跑恢复。输出目录有 `.wx2md.lock`，避免两个 CLI 进程同时修改清单。若进程被强行终止，确认没有任务使用该目录后再手动移除遗留锁。旧图片暂不自动删除，避免误删已有资料。

这是本地 CLI；没有面向多租户网络服务部署进行安全验证。不提供账号登录、聊天记录、私有内容或完整历史列表采集。

## 作为 skill 安装

将整个项目文件夹复制到所用 agent 的 skills 目录。`SKILL.md` 与 `wx2md.py` 保持同目录，无需固定安装路径。

Codex 的 macOS/Linux 用户也可在本项目目录下建立软链接（目标位置已有 skill 时先检查，避免覆盖）：

```bash
mkdir -p "$HOME/.codex/skills"
ln -s "$PWD" "$HOME/.codex/skills/wechat-md"
```

然后说：“用 $wechat-md 阅读这篇文章……”或“把这些文章归档到指定目录……”。
